## Core Principles
- **Think Before Coding:** Explicitly state assumptions and ask for clarification.
- **Simplicity First:** Write the minimum code necessary; avoid over-engineering.
- **Surgical Changes:** Only touch files and lines directly related to the task.
- **Goal-Driven Execution:** Define a success criterion and loop until met.

- Tech Stack: Vite, Supabase, TypeScript.
- Focus: Automation for SERVPRO operations and property management.
